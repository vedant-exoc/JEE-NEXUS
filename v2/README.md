# JEE NEXUS V2

This directory contains the secure-cloud preview version of the app.

## Preview locally

1. Open the repo in VS Code.
2. Install Live Server extension.
3. Right-click `v2/index.html` and choose **Open with Live Server**.
4. The app should open at a localhost preview URL.

## Notes

- This preview keeps the premium dark crimson + neon green aesthetic.
- It includes the invitation/login shell and the secure workspace UI.
- Real Supabase + Netlify integration is scaffolded but requires your project credentials.
- Since a live browser preview is not available inside chat, this is the easiest local preview path.
